# Hi, I'm Rakibul Islam Mehedi

Flutter developer building offline-first finance apps for freelancers. AI safety researcher focused on red teaming and adversarial testing.

## What I Build

**Finance Apps:** The Pocketa ecosystem helps freelancers with unstable income know exactly what's safe to spend. Built with Clean Architecture, Riverpod, and Hive for offline-first reliability.

**AI & Security Tools:** Adversarial Safety Desk generates jailbreak prompts and safety evaluation bundles for authorized LLM red teaming. Research tools for model hardening.

**Developer Resources:** Curated lists for Python, Flutter, and cybersecurity communities.
